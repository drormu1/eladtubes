# סרטונים באתר

## תיקיות
- `home-hero` - סרטון פתיחה (אם רוצים)
- `projects-house-committees` - סרטוני ביצוע מתוך פרויקטים

## הנחיות מהירות
1. העלו קבצי MP4 (מומלץ H.264).
2. שמרו שמות קבצים באנגלית, לדוגמה: `project-video-01.mp4`.
3. עדכנו את הנתיב בקובץ `script.js` כדי להציג את הסרטון במקום הנכון.
