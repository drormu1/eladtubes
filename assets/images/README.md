# תמונות באתר

האתר בנוי כך שאפשר להעלות תמונות לפי אזור הופעה באתר.

## תיקיות
- `home-hero` - תמונת פתיחה מרכזית
- `equipment` - ציוד וכלים
- `clients` - לוגואים/תמונות של לקוחות גדולים
- `projects-house-committees` - פרויקטים לוועדי בתים
- `team` - תמונות צוות

## הנחיות מהירות
1. העלו קבצים בפורמט JPG/PNG/WebP.
2. שמרו שמות קבצים פשוטים באנגלית, לדוגמה: `project-01.jpg`.
3. אחרי העלאה, עדכנו את הנתיב המתאים בקובץ `script.js` כדי שהתוכן יוצג באתר.
